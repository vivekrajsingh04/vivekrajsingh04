## About Me

I am focused entirely on quantitative finance and computational modeling. My work bridges the gap between advanced mathematical theories (stochastic calculus, derivative pricing, factor models) and robust software engineering.

- Quantitative Modeling: Stochastic differential equations, jump-diffusion processes, Monte Carlo simulations.
- Financial Engineering: Derivatives pricing, volatility surface modeling, Value at Risk (VaR).
- Systems Engineering: Developing high-performance, deterministic numerical engines in C++ and Python.

## Featured Projects

<div align="center">

| Project | Description |
| :--- | :--- |
| **[Variance-Gamma-Engine](https://github.com/vivekrajsingh04/variance-gamma-engine)** | Implemented the Variance Gamma option pricing model (Madan, Carr, Chang). Models asset returns as Brownian motion evaluated at random time given by a gamma process, capturing fat tails and skewness in financial returns. Validated against European option market prices. |
| **[Heston-SV-Engine](https://github.com/vivekrajsingh04/heston-sv-engine)** | High-fidelity Heston Stochastic Volatility Model implementation. Features a dual-validation architecture computing prices via Monte Carlo (with Antithetic Variates) and analytical numerical Fourier inversion. Automatically extracts implied volatility smiles and 3D pricing surfaces. |
| **[Stochastic-Storage-VaR](https://github.com/vivekrajsingh04/stochastic-storage-var)** | Modeled stochastic volatility and Value at Risk (VaR) for storage constraints in energy markets. Developed computational engines to evaluate risk under uncertainty using jump-diffusion characteristics. |
